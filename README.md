# Formation Claude pour la finance — Journée 2

Support de la journée 2 de la formation Caledon·IA « L’IA générative au service de la finance ».

Toutes les données de ce dépôt sont **fictives** : la société « Lagon Bleu Équipements SARL », ses clients, ses salariés et ses chiffres sont inventés. Les taux de cotisation sont fictifs et servent uniquement à l’exercice.

## Comment récupérer le dépôt

1. Bouton vert **Code** › **Download ZIP**, puis décompresser le dossier sur votre poste.
2. Ou, si vous utilisez Git : `git clone https://github.com/adrienbock-sys/formation-claude-finance.git`

## Règles du jeu

- On travaille uniquement sur ces données fictives pendant la formation.
- Chaque résultat produit par Claude se vérifie : totaux, équilibre débit/crédit, cohérence des taux.
- Sur vos vraies données : licence entreprise, anonymisation, et respect de la charte IA de votre entreprise.
