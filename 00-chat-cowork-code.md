# Chat, Cowork ou Code : lequel choisir ?

| | **Chat** | **Cowork** | **Code** |
| --- | --- | --- | --- |
| Où | claude.ai, app mobile ou bureau | App Claude pour ordinateur | App de bureau, terminal, éditeur |
| Travaille sur | Ce que vous collez ou importez | Un dossier de votre ordinateur | Un dossier de fichiers, scripts, données |
| Mode | Une question, une réponse | Une tâche en plusieurs étapes, en autonomie | Une tâche technique, en autonomie, avec du code |
| Idéal pour | Rédiger, reformuler, analyser un fichier | Trier 40 factures, rapprocher 12 relevés, produire un dossier | Automatiser un traitement répétitif, connecter une base de données |
| Exemple finance | « Résume ce rapport d’audit » | « Saisis les factures du dossier Achats_Nov dans le modèle Excel » | « Écris un script qui extrait chaque nuit les tickets de caisse et les rapproche de la banque » |

## La règle simple

- Vous **demandez** quelque chose → **Chat**.
- Vous **déléguez** une tâche sur vos fichiers → **Cowork**.
- Vous voulez que la tâche **tourne toute seule** à l’avenir → **Code**.

## Exercice (10 min)

Faites le même travail trois fois avec le dossier `donnees/02-factures-vente/` :

1. **Chat** : importez `commandes_a_facturer.xlsx` et demandez le total TTC par client.
2. **Cowork** : ouvrez le dossier `donnees/02-factures-vente/` et demandez une facture PDF par client.
3. **Code** : demandez un script qui refait ce travail chaque mois à partir d’un nouvel export.

Comparez : temps passé, qualité du résultat, ce que vous avez dû vérifier.
